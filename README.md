# Main Code Block:

Main code block contains:
-full text processing pipeline for NER task on CoNLL annotated data.
-3 experiments designed to find the best performing model 
-1 grid search designed to finetune and evaluate that best model. 

All experiments use Bert models and tokenizers to perform token classification. 

All code is located in the root of the project file. 

All data used in this project is located in ./data

All results discovered in this project are located in ./results
